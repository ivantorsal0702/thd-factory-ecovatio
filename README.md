# THD Factory · Ecovatio Energía Digital

Web corporativa de **Ecovatio Energía Digital**, una empresa ficticia de consultoría e integración de tecnologías habilitadoras digitales (THD) para el sector de la **energía y las renovables**.


## Páginas

| Archivo | Contenido |
|---|---|
| `index.html` | Quiénes somos, THD con las que trabajamos, Industria 1.0 → 5.0 y contacto |
| `catalogo.html` | Fichas de las 10 THD y productos/servicios |
| `sostenibilidad.html` | Economía circular, modelos sostenibles, ciclo de vida, ecodiseño y ODS |
| `mercados.html` | Nuevos mercados y THD emergentes |
| `it-ot.html` | IT frente a OT, convergencia, ciberseguridad y caso de éxito |
| `informe.html` | Informe técnico, glosario y webgrafía |
